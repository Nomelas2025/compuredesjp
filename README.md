# Final Project - Advanced Styling with Responsive Design

## Included
- Mobile-first one-column CSS Grid with 10px gap.
- Tablet breakpoint at 772px with two columns, circular figures, and the last figure spanning both columns.
- Large-screen breakpoint at 992px with every third figure spanning both columns and no figure border radius.
- `prefers-reduced-motion` query that disables smooth scrolling.
- `prefers-color-scheme: dark` query with dark figure backgrounds, light text, and black borders.
- Nine replacement local SVG images with descriptive alt text.
- Replacement paragraph content.
- No `max-width` media-query rule.
